# April & The AristoCats

An ongoing, episodic choose-your-own-adventure serial in an old
comic-book style. New episode roughly weekly or every two weeks.

## What it is

You're at the helm of your tiny home when a rogue semicolon in a
Python script rips a hole in space-time — and Khaleesi and ZZ are
staring at you expecting a fix. JavaScript drives the story from a
story data structure (not a page per scene), and branching choices
lead somewhere different.

## How to read it

This is a living serial, not a finished book. Open `index.html` in a browser.
New episodes are added as they are written.

## Status

Ongoing. Later branches are still being written.
